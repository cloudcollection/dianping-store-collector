# 店迹 RPD

版本：3.1  
产品版本：2.0.0  
日期：2026-07-26

## 1. 产品定义

店迹是一个本地优先的 Manifest V3 浏览器采集工作台。它在用户已经登录并能正常访问的大众点评页面中，按指定搜索范围建立固定店铺队列，顺序采集店铺详情、团购套餐和代金券，并将数据保存到用户自己的 MongoDB。

产品重点不是高并发，而是：

- 范围明确；
- 队列固定；
- 写入可追溯；
- 失败会停止；
- 中断后可恢复；
- 数据不离开用户本机。

## 2. 目标用户

- 需要小批量整理店铺公开信息的研究、运营或开发人员；
- 能理解网站页面会变化、登录态会失效的用户；
- 希望数据保存在自有 MongoDB 的用户。

## 3. 非目标

- 验证码、滑块或登录限制绕过；
- Cookie 导出；
- 代理池与账号池轮换；
- 自动化特征隐藏；
- 多标签并发和无人值守大规模采集；
- 对未来所有页面版式的永久兼容承诺。

## 4. 核心流程

1. 用户启动本地服务，终端显示随机配对令牌。
2. 用户在扩展侧边栏完成配对。
3. 扩展验证后端版本、MongoDB 状态和任务范围。
4. 扩展直接打开指定开始页，逐条写入本次搜索事实。
5. 系统按店铺 ID 去重并建立包含稳定序号的固定队列。
6. 已有完成提交标记的店铺自动跳过。
7. 其他店铺顺序进入详情页，在同一页面中提取详情与可见优惠。
8. 页面不存在优惠栏目时允许空数组；检测到栏目但解析为空时暂停。
9. 店铺快照、优惠明细和完成提交标记依次幂等写入。
10. 全部成功后才推进队列；任一步失败均保留当前店。
11. 用户处理登录、验证或数据库故障后继续原任务。
12. 用户使用一次性凭证导出安全 CSV。

## 5. 任务配置

- 任务范围：完整流程、仅搜索、仅店铺页、当前页；
- 城市编号；
- 店铺关键词；
- 开始页与截至页：`1–30`；
- 当前页内开始序号：`1–15`；
- 本次采集数量：`1–100`；
- 是否采集优惠；
- 快速或稳妥节奏。

系统在任务开始前计算页面范围容量，采集数量不得越过截至页。

## 6. 数据要求

### shops

每家店一条当前快照，只保留：

- `店铺id`
- `店铺名`
- `评论总数`
- `人均价格`
- `标签`
- `店铺地址`
- `店铺均分`
- `推荐菜`
- `店铺总分`
- `优惠券信息`
- `最后采集时间`
- `首次采集时间`

店铺名、地址和总分作为身份阻断字段。评论数、人均、标签、均分和推荐菜允许合法缺失，并返回完整性提示。

### search_results

保存 `task_id`、固定序号、店铺 ID、搜索来源、页码、采集时间和当时的搜索快照。

### deals

团购套餐和代金券共用兼容明细集合。唯一键优先使用店铺 ID 与页面优惠 ID；没有 ID 时使用稳定内容指纹。

不得从标题猜测原价、折扣、面值或规则。

### shop_commits

保存店铺的最终完成状态。只有店铺和优惠全部成功后才写入，用于恢复时判断是否可跳过。

### network_captures

MongoDB 只保存响应哈希、来源、状态和本地证据路径；完整正文保存在受容量与保留期限制的本地目录。

## 7. 安全要求

- 服务只监听 `127.0.0.1`；
- 业务接口必须携带随机 `X-Collector-Token`；
- CORS 只允许浏览器扩展来源；
- 请求正文最大 6 MB；
- 单条网络证据最大 5 MB；
- 原始证据默认最多 250 MB、保留 14 天；
- CSV 下载凭证有效 60 秒且只能使用一次；
- CSV 危险公式前缀必须文本化；
- 配对令牌、数据、日志、虚拟环境和浏览器配置不得进入版本库。

## 8. 恢复与一致性

- 扩展保存 `task_id`、固定队列、当前项、完成数和跳过数；
- 浏览器重启后默认暂停；
- MongoDB 恢复后自动重连；
- 结构化写入先进入本地原子镜像，再进入 MongoDB；
- 重连成功后本地镜像按采集时间重放；
- 缺少 `shop_commits` 的店铺不会被误判为完成；
- “继续上次”不重新搜索或重排旧队列；
- “开始搜索”创建新 `task_id` 和新队列。

## 9. 访问限制策略

快速：

- 普通等待 10–20 秒；
- 每批 3–7 次动作；
- 批次休息 30–90 秒。

稳妥：

- 普通等待 30–90 秒；
- 每批 2–5 次动作；
- 批次休息 90–240 秒。

等待和批次均使用浏览器安全随机源。登录页、验证页、验证码、限制文本或 HTTP 401/403/406/429/503 会立即暂停。
